# Drill

30 minutes a day. Mon/Wed/Fri SQL, Tue/Thu/Sat NeetCode.

- `neetcode/<problem_name>.py`: solution + a short docstring (pattern, time/space complexity, the trick). Add a few `assert`s at the bottom.
- `sql/<platform>_<problem_name>.sql`: query + a comment with the pattern (join, CTE, window …).

Mark a problem `# REDO` in its docstring if I needed a hint; redo those on Sundays.
