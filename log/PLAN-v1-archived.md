# Parallel learning plan (25 Sep → 30 Nov 2026)

Job-ready depth, not expert depth. Four tracks run every day, in parallel. Project work is separate.

## Daily template (~3.5–4 h)
| Block | Time | What |
|---|---|---|
| **DSA** | 60 min | Learn the pattern (Padho with Pratyush), then solve 2 NeetCode problems |
| **ML core** | 60 min | One concept (StatQuest / ISLP), then write 5 lines of notes + 3 interview questions in `notes.md` |
| **Practical** | 60–75 min | Code today's ML concept in a notebook, saved in the day folder |
| **Essentials** | 30–45 min | Rotates: SQL · engineering (Git, Docker, FastAPI, testing) · career (CV, applications, behavioural) |

If a day is short: never skip DSA or ML core; Practical comes next; Essentials can move to another day.
Sunday: quiz + review the week's `notes.md`, afternoon off.

## Daily routines (Mon–Sat)
- **LinkedIn (15–20 min):** comment thoughtfully on 3 posts + 2 personalised connection requests. **Post every Wednesday** (one thing learned or built, with a visual or code). Saturday: reply to comments/DMs, draft next post.
- **Job search (20–40 min):** Week 0 builds the pipeline (skills tally, job sheet, alerts, 20 target companies). Week 1 saves roles while CV v1 is finished. From Week 2: Mon 2 tailored applications, Tue–Thu 1, Fri 1 + message an engineer/recruiter, Sat follow-ups (> 7 days). About 6 a week.
