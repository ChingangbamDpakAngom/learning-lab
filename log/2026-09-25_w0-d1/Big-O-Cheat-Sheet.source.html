7Space complexity (extra memory)

  • O(1): a few variables; in-place swaps (a.sort(), two pointers)
  • O(n): new list/set/dict of n items; sorted(a); a[::-1]
  • Recursion: every unfinished call sits on the stack → depth d costs O(d)
  • Amortised O(1): append sometimes copies everything, but rarely enough that the average stays O(1)
The #1 trade: memory for speed 
seen = set()                # O(n) space
for x in a:                 # O(n) time
    if x in seen: return True
    seen.add(x)
Nested-loop duplicate check: O(n²) → hash set: O(n)

How to say it in the interview

"It's O(n) time, where n is the length of the array, because I pass through it once and each set lookup is O(1) on average. Space is O(n) for the set. The brute force was O(n²); I traded memory for time."

Checklist

  • Find every loop, including hidden ones
  • Nested → multiply · sequential → add · halving → log
  • Name each input: O(a·b), not O(n²)
  • Always give time AND space, and define n
  • Start from brute force, then improve out loud
