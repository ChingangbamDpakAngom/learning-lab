2Spread: variance & SD, worked by hand

x = [2, 4, 4, 4, 5, 5, 7, 9] → mean = 5

Deviations x − x̄−3 −1 −1 −1 0 0 2 4 → sum is always 0
Squared9 1 1 1 0 0 4 16 → sum = 32
Variance (population, ÷ n)32 / 8 = 4  (units²)
SD = √variance√4 = 2  ← back in original units
Sample (÷ n−1, Bessel)32 / 7 = 4.57 → SD 2.14
Why square? Stops + and − cancelling, and punishes big misses more. Why n−1? Deviations from the sample mean underestimate the true spread.
Gotcha: np.var(x) uses ÷n (ddof=0) · pandas s.var() uses ÷(n−1) (ddof=1)

4Percentiles, IQR & outliers (box plot)

outlier if < Q1 − 1.5·IQR  or  > Q3 + 1.5·IQR

Salaries: Q1 = 28.5, Q3 = 34.25, IQR = 5.75 → upper fence 42.9 → 300 is an outlier

In production: latency is reported as p50 / p95 / p99, not the mean. p99 = the slowest 1% of requests, and those are the users who complain.

5z-score: same scale for everything

z = (x − mean) / SD

How many SDs from the mean. Score 80, mean 70, SD 5 → z = +2 (unusual).

  • Normal data: 68 / 95 / 99.7 % within 1 / 2 / 3 SD
  • |z| > 3 → flag as outlier
  • StandardScaler = z-score every feature

7Where ML engineers use it

  • EDA: df.describe() + histograms first
  • Skewed feature: log-transform it
  • Missing values: fill with median if skewed
  • CV results: report mean ± SD over folds
  • Drift: compare today's distribution vs training

8Code you'll actually write

import numpy as np, pandas as pd
x = np.array([2, 4, 4, 4, 5, 5, 7, 9])
x.mean(), np.median(x)            # 5.0, 4.5
x.std(), x.std(ddof=1)            # 2.0 (population), 2.14 (sample)
q1, q3 = np.percentile(x, [25, 75])
iqr = q3 - q1

s = pd.Series([25, 28, 30, 32, 35, 300])
s.describe()      # count, mean, std (ddof=1), min, 25%, 50%, 75%, max
s.skew()          # 2.44 > 0 → right-skewed
s.plot.hist(bins=30); s.plot.box()

9Interview questions: one-line answers

Median over mean when?Skewed data / outliers; median is robust
Variance vs SD?SD = √variance, in original units
Why n−1?Sample mean sits inside the data → spread underestimated
Mean > median means?Right-skewed: long tail of large values
Detect outliers?1.5×IQR rule, |z| > 3, and look at the plot
Why p99 not mean latency?Mean hides the slow tail users feel

How to say it in the interview

"First I'd plot the distribution. This feature is right-skewed, since the mean is well above the median, so I'd summarise it with the median and IQR, flag outliers with the 1.5×IQR rule, and log-transform it before modelling. Numeric features get standardised with z-scores so they're on the same scale."
