Two Pointers Cheat Sheet

Two indices walk the data together so one pass replaces a nested loop: O(n²) → O(n), usually O(1) extra space

DSA pattern · Week 2Sorted? Pairs? In place? Think two pointers.

1Spot it: signals in the problem

If the problem says…Reach for
Sorted array + find a pair / triplet with a target sumOpposite ends
Palindrome, reverse in place, "compare both ends"Opposite ends
Maximise area / width between two linesOpposite ends
Remove duplicates / zeros / a value in place, O(1) spaceRead / write
Merge two sorted lists, "is a subsequence of"Two sequences
Linked list cycle / middle nodeFast / slow (week 4)

Unsorted + "find a pair"? Use a hash map (Two Sum, O(n)), or sort first (O(n log n)) if indices don't matter.

2Why it works: every move throws away options safely

Sorted array, looking for a[L] + a[R] = 9:

1245711

1 + 11 = 12 > 9 → too big. 11 plus anything is ≥ 12, so 11 can never be in the answer → R−−

1245711

1 + 7 = 8 < 9 → too small. 1 plus anything left is ≤ 8, so 1 is useless → L++

1245711

2 + 7 = 9 ✅ found. Each step removes one element for good → at most n steps → O(n)

3The three templates (memorise these)

A. Opposite endsStart at both ends, move inward. Needs order (sorted / symmetric).

·→←·
l, r = 0, len(a) - 1
while l < r:
    s = a[l] + a[r]
    if s == target:
        return [l, r]
    if s < target:
        l += 1        # need bigger
    else:
        r -= 1        # need smaller

B. Read / write (same direction)r reads every item, w marks where the next kept item goes.

010312
w = 0
for r in range(len(a)):
    if keep(a[r]):        # e.g. a[r] != 0
        a[w] = a[r]
        w += 1
return w                  # new length
# Move Zeroes: swap a[w], a[r] instead

C. Two sequencesOne pointer per input; advance the one that "loses".

147239
i = j = 0
out = []
while i < len(a) and j < len(b):
    if a[i] <= b[j]:
        out.append(a[i]); i += 1
    else:
        out.append(b[j]); j += 1
out += a[i:] + b[j:]      # leftovers

4Your problems: the one idea that cracks each

Valid Palindrome Easy

Opposite ends; skip non-alphanumerics, compare lowercase.

l, r = 0, len(s) - 1
while l < r:
    if not s[l].isalnum(): l += 1
    elif not s[r].isalnum(): r -= 1
    elif s[l].lower() != s[r].lower(): return False
    else: l += 1; r -= 1
return True

O(n) time · O(1) space (no cleaned copy needed)

Two Sum II (sorted input) Medium

Template A exactly. Sum too small → l += 1; too big → r -= 1. Return 1-indexed positions.

O(n) time · O(1) space. Beats the hash-map version on space because the input is already sorted.

Container With Most Water Medium

Area = (r − l) × min(h[l], h[r]). Always move the shorter line: the width only shrinks, so keeping the short line can never give a bigger area.

l, r, best = 0, len(h) - 1, 0
while l < r:
    best = max(best, (r - l) * min(h[l], h[r]))
    if h[l] < h[r]: l += 1
    else: r -= 1

3Sum Medium = sort + fix one number + Two Sum II on the rest → O(n²) time, O(1) extra space (besides output)

a.sort(); res = []
for i in range(len(a) - 2):
    if i > 0 and a[i] == a[i - 1]: continue          # skip duplicate anchors
    l, r = i + 1, len(a) - 1
    while l < r:
        s = a[i] + a[l] + a[r]
        if s < 0: l += 1
        elif s > 0: r -= 1
        else:
            res.append([a[i], a[l], a[r]]); l += 1; r -= 1
            while l < r and a[l] == a[l - 1]: l += 1   # skip duplicate lefts

5Bugs interviewers watch for

  • l < r vs l <= r: pairs need two different elements → l < r. (<= is for binary search.)
  • Forgetting to sort: opposite-ends only works on sorted / ordered data. Sorting costs O(n log n) and loses original indices.
  • Duplicates in 3Sum: skip repeated anchors and repeated left values after a hit, or you return the same triplet twice.
  • Infinite loop: every branch must move at least one pointer.
  • Off-by-one: r = len(a) - 1, not len(a). Two Sum II wants 1-indexed output.
  • Moving the wrong side in Container: move the shorter one, never the taller.

6Two pointers vs neighbours

Sliding windowContiguous subarray / substring with a condition (next topic)O(n) · O(k)
Brute forceSay it first, then improveO(n²)

A sliding window is a same-direction two-pointer: l and r bound a range instead of pointing at two items.

How to say it in the interview

"Brute force checks every pair, O(n²). Because the array is sorted, I put one pointer at each end: if the sum is too small I move left up, if it's too big I move right down. Each step rules out one element for good, so it's O(n) time and O(1) space."
