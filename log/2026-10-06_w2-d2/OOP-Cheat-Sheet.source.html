1Class, instance, self, class variables

class Employee:
    raise_amt = 1.04             # CLASS variable: shared by all
    num_of_emps = 0

    def __init__(self, first, last, pay):
        self.first = first       # INSTANCE variable: one per object
        self.pay = pay
        Employee.num_of_emps += 1   # shared counter: use the class name

    def apply_raise(self):       # self = the object it was called on
        self.pay = int(self.pay * self.raise_amt)

emp_1 = Employee('Corey', 'Schafer', 50000)
emp_1.apply_raise()   # same as Employee.apply_raise(emp_1)
Lookupself.x: instance first, then class, then parent (the MRO). First match wins
Trapemp_1.raise_amt = 1.05 creates an instance copy on emp_1 only
Trapa variable inside __init__ without self. is local: gone after init

2Three kinds of method

def apply_raise(self): ...          # about ME (one object)

@classmethod
def set_raise_amt(cls, amount):     # about OUR SCHOOL (the class)
    cls.raise_amt = amount

@classmethod
def from_string(cls, s):            # alternative constructor
    first, last, pay = s.split('-')
    return cls(first, last, int(pay))   # cls → works for subclasses

@staticmethod
def is_workday(day):                # about NEITHER: plain helper
    return day.weekday() < 5
Ruleuses self → normal · only cls → classmethod · neither → staticmethod
Bracketsmethods need (), values don't: day.weekday() vs emp.raise_amt

3Inheritance + abstraction

class Developer(Employee):
    raise_amt = 1.10                 # override the parent
    def __init__(self, first, last, pay, lang):
        super().__init__(first, last, pay)   # reuse parent setup
        self.lang = lang

class Manager(Employee):
    def __init__(self, first, last, pay, employees=None):
        super().__init__(first, last, pay)
        self.employees = [] if employees is None else employees

from abc import ABC, abstractmethod
class Shape(ABC):
    @abstractmethod
    def area(self): ...      # Shape() → TypeError until a child implements it

Never employees=[]: the default list is made once and shared by every object. isinstance(obj, Class) checks an object; issubclass(A, B) checks a class.

4@property + __repr__ (encapsulation)

@property
def email(self):                    # read like an attribute
    return f"{self.first}.{self.last}@email.com"

@fullname.setter
def fullname(self, name):           # emp.fullname = 'Corey Schafer'
    self.first, self.last = name.split()

@fullname.deleter
def fullname(self):                 # del emp.fullname
    self.first = self.last = None

def __repr__(self):                 # developer view: lists, REPL, logs
    return f"Employee({self.first!r}, {self.last!r})"
Whystored in __init__ = photo (goes stale) · property = mirror (always current)
Private?none in Python: _x = convention, __x = name mangling
str vs repr__str__ for users · __repr__ for developers (fallback for both)

5The 4 pillars + interview answers

EncapsulationBundle data + methods and control access: @property, _name
AbstractionHide details, force a contract: ABC + @abstractmethod
InheritanceReuse parent code: class Developer(Employee) + super()
PolymorphismSame method, different behaviour: for s in shapes: s.area() (plus duck typing)
What is self?The instance the method was called on. Not a keyword, a convention. Forget it → TypeError: takes 0 positional arguments but 1 was given
Is __init__ the constructor?Not strictly: __new__ creates the object, __init__ fills it in
