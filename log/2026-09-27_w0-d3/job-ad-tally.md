## Takeaways
1. **Python + SQL + pandas/scikit-learn is the core** of every junior ML ad. The W1–W2 plan covers exactly this.
2. **DA roles want SQL + Power BI + data quality + documentation**. That's the NHS project (W2–W3).
3. **Docker, MLOps and CI/CD set you apart at junior level** but aren't required. Aegis already shows them.
4. **Cloud is rarely required for junior roles**, so keep it for December, as planned.
5. **Communication is in 9/10 ads.** Practise explaining each project in 2 minutes.
6. Junior salaries: **£26–45k**. £40k+ needs ML roles, UCL-type roles or NHS Band 6, which matches PLAN.md.
7. Caution: firms like ITC that want "immediate joiners" with a "Master's required" are sometimes train-and-place schemes that charge fees. Check reviews before applying.
