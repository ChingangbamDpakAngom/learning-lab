5Interview questions

List vs tuple?List is mutable; tuple is immutable, so it's hashable (dict key) and signals a fixed record.
Why is items=[] a bug?Defaults are built once at def time, so every call shares and mutates the same list. Use None.
How is dict lookup O(1)?The key's hash picks a slot directly; no scan. Average O(1), worst O(n) with many collisions.
Shallow vs deep copy?Shallow copies the outer container only; inner objects are shared. Deep copies everything, recursively.
Generator vs list?Generator yields items one at a time with O(1) memory and can be consumed once; a list holds all items.
