np.concatenate([a, b], axis=0)join along an existing axis
np.vstack · np.hstackadd rows · add columns
np.stack([a, b])join along a new axis: (3,) ×2 → (2, 3)

5Maths (element-wise, no loops)

a + b · a * 2 · a ** 2every value at once (vectorised, C speed)
np.sqrt · np.exp · np.logsoftmax, log-loss, scaling
np.abs · np.round(a, 2)errors (MAE) · tidy output
np.clip(a, 0, 1)limit to a range (probabilities)
np.diff(a, axis=0)change between neighbours (function, not method)

np.linalg.norm(a, axis=1)vector length (cosine, normalising)
np.allclose(a, b)float "equal" for tests; never == on floats

6Reduce with axis

axis=1collapse columns → one result per row

np.median · np.percentile(a, 95)skew-proof centre · p95 latency
a.cumsum()running total
np.nanmean · np.nansumignore NaN (plain mean returns nan)

9Gotchas interviewers love

View vs copya slice is a view: editing it changes the original. Use .copy().
(n,) vs (n, 1)1-D vector vs column: broadcasting differs. Print .shape.
Shape error"operands could not be broadcast": trailing dims must match or be 1.
dtype truncationputting 2.7 in an int array silently stores 2.
NaN spreadsone NaN makes mean NaN; use nanmean or clean first.
max vs argmaxvalue vs position; np.where(cond) alone gives positions too.
len(2-D)= rows only. Columns = a.shape[1].

✓Interview lines

Why NumPy? Arrays of one type in contiguous memory, with loops running in C: vectorised code is 10–100× faster than Python loops. axis? The axis you name is the one that disappears: axis=0 gives one result per column. Broadcasting? NumPy stretches size-1 or missing dimensions so (4, 3) − (3,) works without copying. Cosine similarity? Dot product of length-normalised vectors: it ranks embeddings by direction, not size.
