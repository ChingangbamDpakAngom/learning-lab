✓Interview lines

First thing with a new dataset? shape, dtypes, missing values, duplicates, value counts: then decide how to clean. Drop or fill missing values? It depends on why they're missing: drop when rows are few or unusable, fill when a sensible default exists, and say which you chose. Merge vs concat? merge joins on keys like SQL; concat stacks tables. After a merge? Check the row count. Why not loop over rows? Column operations run in C (NumPy underneath); apply and loops are Python-speed.
