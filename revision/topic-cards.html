Topic Cards

Understand it, don't memorise it. Each card starts with a plain-English story, then the four parts. Turn on Recall mode, explain the topic out loud as if to a friend, then reveal and compare. Rate yourself, and revise the shaky ones first.

  • Whatwhat it is
  • Whywhy we need it
  • Howthe few lines to know
  • Solvesthe problem it fixes
  • Whenwhen to use it, and when not
A new card is added after every topic. "Where I've used it" lists only real work (drills, labs, Aegis, NHS); planned work says so. Links open the cheat sheet or notes on GitHub. Ratings stay in this browser.
